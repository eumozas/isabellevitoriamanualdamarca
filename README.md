# Isabelle Victoria — Manual da Marca

Manual de identidade visual da cantora Isabelle Victoria: logotipos (PNG e SVG em todas as cores), paleta, tipografia, voz e tom, e aplicações prontas para download.

Abra o `index.html` ou publique pelo GitHub Pages (Settings → Pages → branch `main`, pasta raiz).
